# 更名任务：NutriSphere → 饮食球（DietSphere）

## 决定

项目中文主名改为 **饮食球**，英文副名为 **DietSphere**。

保留教育/研究工具边界与免责声明原文不变。

## 更名范围

### 1. 文档与品牌
- `README.md`：标题、简介、Vision 等全部更新。
- `docs/PROJECT_VISION.md` 及其他 docs 中的 NutriSphere 引用。
- 界面品牌（顶栏、大厅、免责声明栏、关于页）。
- 保留过渡说明：「原 NutriSphere」（可放在关于或 README 底部）。

### 2. 代码与界面
- 顶栏品牌文案、页面 title、meta 描述。
- 任何硬编码的「NutriSphere」字符串。
- 分享链接、复制提示等用户可见文案。
- 不改变功能逻辑、数据字段、免责声明正文。

### 3. 仓库与部署
- 仓库名可保留 `nutri-sphere` 或重命名为 `diet-sphere`（由维护者决定）。
- GitHub Pages 路径若仓库重命名需同步更新。
- package.json 名称、构建产物中的标题。

### 4. 不改的内容
- 数据文件内的证据摘录与字段。
- 免责声明原文。
- 现有任务卡编号与历史提交说明（可在新提交中注明更名）。

## 验收

- 界面与 README 均显示「饮食球」。
- 搜索仓库内用户可见的 NutriSphere 已替换或注明过渡。
- 功能不回退，免责声明仍可见。
- 文案守卫通过。

## 优先级

1. 先更新界面品牌与 README。
2. 再全局替换文档中的引用。
3. 最后处理仓库名与部署路径（若需要）。
