# 用户路径观察记录模板

用于 Phase 1.5 用户验证。每位观察者填一份（或你代为记录）。

## 基本信息

- 日期：
- 观察者（可匿名）：
- 背景：非营养/医学专业 / 其他：
- 使用设备：桌面 / 手机
- 任务前是否看过任何说明：否

## 任务步骤（请按顺序完成，不给提示）

1. 打开站点首页（主题大厅）。
2. 自己选一个感兴趣的主题卡片，进入。
3. 在图上点 1–2 条边（或节点），看侧栏。
4. 回答下列问题（口述即可）。

## 观察记录

### 进入后的图

### 点击边/节点后
- 侧栏里看到了什么？（请让用户原话说）
- 是否注意到方向（保护/风险）？是 / 否
- 是否注意到局限性或「非个人建议」类说明？是 / 否
- 是否注意到底部免责声明？是 / 否

### 离开时的理解
- 用户原话：「这是建议我改变饮食吗？」
- 用户原话：「证据强度怎么看？」
- 用户原话：「有什么限制？」
