# ClearDiet 画布壳层：整体布局重构开发方案

状态：已实现。PR-A / PR-B / PR-C 已在 `cursor/shell-canvas-workspace` 完成，并通过本地测试、构建、数据校验与无头浏览器验收。

产品名沿用现有界面文案「明膳知源」（ClearDiet）。教育边界不变：公开资料里的饮食、机制与健康结局关联，界面保持「仅供学习 / 饮食观察，非诊断」，不出现疗效、诊断、处方或个人风险分数。

视觉令牌继续用 `src/styles/tokens.css` 与 `docs/UI_PRO_REDESIGN.md` 里已落地的间距、圆角和方向色。本方案只重排壳层，不重做图谱算法、孪生映射公式或种子数据。

---

## 1. 设计原则

1. **主体是一块可视化画布。** 用户打开应用后，视口里最大的区域始终是画布，而不是文档式大厅或顶栏导航页。
2. **左栏是唯一的全局导航与工具架。**
   - 桌面（宽度大于 768px）：同一条左栏在「全展开大栏」和「仅图标小栏」之间切换，两种都占位，不盖住画布。
   - 手机（宽度不大于 768px）：同一条左栏只有「抽屉全开」和「全关」两态。全关时画布占满宽度；全开时抽屉盖住画布，并有遮罩。手机不做「仅图标常驻条」，避免再挤掉画布。
3. **主窗口只有两个工作区：图谱画布、我的饮食数字孪生。** 顶栏里的「主题大厅 / 图谱探索」双按钮，以及把孪生做成第三块整页，都退出主结构。主题、搜索、筛选、领域切换进入左栏；来源页、饮食方式详情、节点详情仍是画布上的次级层，不取代工作区。

## 2. 现状（作为迁移起点）

当前壳层在 `src/App.tsx`，样式在 `src/styles.css`。

| 区域 | 现在怎么排 | 和目标的差距 |
|------|------------|----------------|
| 顶栏 `.topbar` | 品牌、桌面双按钮（主题大厅 / 图谱探索）、领域切换、探索时搜索、手机汉堡菜单 | 导航和品牌占掉画布上方一整行；大厅与图谱是并列页面 |
| 大厅 `ThemeLobby` | `screen === 'home'` 时整页卡片、搜索、「先看这些」、进入孪生入口 | 大厅是第三块主表面，不是画布 |
| 探索 `.stage--explore` | 桌面网格 `300px + 画布`，左栏 `.explore-rail` 常驻；选中节点时再加右栏。手机左栏滑出，由「主题/筛选」按钮打开 | 桌面左栏不能收成图标条；左栏只在探索页存在 |
| 孪生 `DietTwin` | `screen === 'twin'` 整页替换舞台，自带返回 | 孪生不是与图谱并列的画布工作区 |
| 详情 | 桌面右栏或覆盖层；手机底部抽屉 `.drawer` | 保留。它是画布上的阅读层，不是左栏 |
| 管理端 | `AdminShell` 自有侧栏 | 本方案不改管理端信息架构，只保证从用户壳层进入后仍是独立舞台 |

断点今天并不统一：壳层用 `useMediaQuery('(max-width: 768px)')`，部分样式用 `720px` / `1024px`。本方案把「手机抽屉 / 桌面双态左栏」的分界固定为 **768px**。

分享参数在 `src/lib/shareUrl.ts`：`ScreenMode` 含 `home | explore | pattern | compare | twin | source | admin`。布局重构后，用户主路径只保留 `explore` 与 `twin` 两种工作区；`home` 作为旧链接的别名，打开后进入图谱工作区。

## 3. 目标结构

```
桌面
┌────────┬──────────────────────────────┐
│ 左栏   │  工作区画布                    │
│ 大栏   │  · 图谱（GraphCanvas）         │
│ 或     │  · 或 饮食数字孪生             │
│ 图标栏 │  画布上浮动：图例、视图切换、   │
│        │  节点/来源阅读层               │
└────────┴──────────────────────────────┘

手机（抽屉关）          手机（抽屉开）
┌──────────────────┐   ┌────────┬─────────┐
│ 画布满宽          │   │ 抽屉   │ 遮罩    │
│ 左缘打开把手      │   │ 全高   │ 点按关闭│
└──────────────────┘   └────────┴─────────┘
```

应用根节点从「顶栏 + 舞台 + 免责条」改为：

```
.app
  .shell                    /* 横向：左栏 + 工作区 */
    .shell-rail             /* 桌面占位；手机 fixed 抽屉 */
    .shell-workspace        /* 唯一主窗口 */
      .workspace--graph | .workspace--twin
      次级层（详情、来源、饮食方式、空领域）
  .disclaimer               /* 现有免责条留在最底，不进左栏滚动 */
```

桌面不再保留与左栏重复的 `.topbar` 主导航。工作区内部需要的控件（通路 / 层次 / 三维、复制链接、旋转）以画布 HUD 形式留在画布角上，沿用现有 `.hud`、`LayoutToggle`，避免为它们再加一条顶栏。

## 4. 左栏

### 4.1 两种桌面形态

| | 全展开大栏 | 仅图标小栏 |
|--|------------|------------|
| 宽度 | 280px（与今天探索栏接近，略收以让出画布） | 64px |
| 占位 | 是，工作区变窄 | 是，工作区变宽 |
| 默认 | 宽度 ≥ 1280px 时默认展开 | 769–1279px 默认图标栏 |
| 记忆 | `localStorage` 键 `cleardiet.shellRail`：`expanded` \| `collapsed`。不写入分享 URL | 同左 |
| 切换 | 栏底一枚按钮：「收起导航」/「展开导航」。图标栏每一项 `title` + `aria-label` 使用现有中文短句 | 同左 |

大栏纵向分区（从上到下，可滚动，底部分割固定）：

1. **品牌。** 「明膳知源」+ 现有一句副文案「仅供学习：饮食、机制与健康结局的关联图谱」。图标栏只留现有 `.mark`。
2. **工作区切换。** 两项，互斥，`aria-current="page"`：
   - 图谱
   - 我的饮食
3. **随工作区变化的工具。**
   - 图谱：搜索（现有 `SearchBar`）、领域（现有 `DomainSwitcher`）、「先看这些」三张推荐（植物性饮食、动物性食物、添加糖，文案仍来自 `exploreShell` / `lobbyEntry`）、主题列表（现有 `ThemeBar`）、筛选（现有 `FilterPanel`：疾病、机制、隐藏非匹配）。
   - 我的饮食：教育标记「饮食观察，非诊断」、记录入口与假设控件（从 `DietTwin` 里拆出的输入区，见第 5 节）。图标栏不展开这些表单，只保留「我的饮食」图标；点它若当前已在孪生且栏是收起的，则展开大栏。
4. **栏底。** 外观主题（现有 `ThemeSwitcher`）、方法说明入口。管理端不放进普通用户主列表；保留今天的隐藏入口或直接 URL（`screen=admin`），不在本方案里新增入口文案。

图标栏只放：品牌标记、图谱、我的饮食、搜索（点按后就地弹出与大栏相同的搜索框，或先展开大栏再聚焦搜索——实现时二选一，优先「先展开再聚焦」，少做一套浮层）、展开按钮、外观主题。主题芯片、筛选、记录表单不塞进 64px。

### 4.2 手机抽屉

- 全关：左栏不占位，`hidden` 或移出可访问树以外的视觉，但关闭按钮与打开把手仍在。画布左上保留一枚「打开导航」图标按钮（沿用今天 `rail-toggle` 的位置逻辑，文案改为「导航」）。
- 全开：自左缘覆盖，宽度 `min(360px, 100% - 48px)`，高度 100%，右侧留下可点的遮罩关闭。内容与桌面大栏相同，字号和点击热区不缩小到图标态。
- 打开时焦点进入抽屉第一个控件，`Esc` 与遮罩关闭，并把焦点还给打开按钮。
- 选中「图谱」或「我的饮食」、或从搜索结果进入某个节点后，抽屉自动全关，把画布还给用户。在抽屉内改筛选、改主题时不自动关闭，避免连续点选被打断。
- 不做半开。不做底部 Tab 替代左栏。

### 4.3 和右侧阅读层的关系

节点 / 边详情（`DetailDrawer`）、来源页（`SourceDetail`）、植物性饮食方式详情（`VeganDietDetail`）仍附着在**工作区**上，不放进左栏。

- 桌面宽屏（> 1024px）且左栏展开时：若同时打开详情，工作区内部再分「画布 | 阅读层」，左栏宽度不变。总列宽不够时阅读层改为覆盖画布右侧，而不是把左栏挤成图标栏。
- 手机：阅读层维持今天的底部抽屉。左栏抽屉与底部阅读层不同时抢手势：左栏打开时不响应阅读层拖拽。

## 5. 主窗口：两个工作区

### 5.1 图谱

- 组件仍是 `GraphCanvas`，数据流（`focus`、`layout`、`graphView`、`lens`、层次边预算）不变。
- 画布铺满 `.shell-workspace`。图例、计数、层次预算说明留在画布内 HUD。
- 无主题、无筛选时的空状态仍用现有短提示（`EXPLORE_EMPTY_COPY`），主按钮改为「打开导航」并展开左栏（桌面展开大栏，手机打开抽屉），不再把用户送回一整页大厅。
- 搜索选中节点后：工作区保持图谱，镜头与今天 `enterLens` / 搜索命中行为一致。

### 5.2 我的饮食数字孪生

- 孪生成为第二种画布，而不是 `onBack` 才能离开的整页。
- 工作区主体：现有人体轮廓与指标可视化，持久短标记「饮食观察，非诊断」，以及今天已经在屏上的教育句（`DietTwin` 顶部那段）。不新增分数、诊断或「建议你吃」。
- 大栏 / 手机抽屉里放记录与假设：日期、餐次、一句话记录、粘贴、7/30 天列表、假设切换。这些控件从 `DietTwin` 的页面流挪到左栏插槽，画布只保留「看见模拟结果」和「点指标回到图谱」。
- 图标栏时：孪生画布仍满宽；左栏不显示表单。画布上保留一枚「记录」按钮，点击后展开大栏（手机则打开抽屉）并聚焦记录输入。
- 点指标：调用现有 `openTwinIndicator`，工作区切回图谱并带上对应焦点。左栏高亮回到「图谱」。返回孪生时恢复切走前的记录与假设（组件状态上提到 `App`，或保持 `DietTwin` 挂载不卸载）。实现时**不要卸载**孪生存储读写逻辑，`dietTwinStore` 仍只写本地。

### 5.3 不再作为主窗口的表面

| 现表面 | 去向 |
|--------|------|
| 主题大厅整页 | 取消主窗口身份。「先看这些」、主题列表、大厅搜索并入左栏图谱工具。比较入口若仍需要，作为左栏里的一个动作，打开后工作区仍是图谱 |
| 饮食方式详情、来源详情 | 工作区内的阅读层，带返回，返回的是当前工作区而不是大厅 |
| 管理端 | 独立舞台，不套这套「图谱 / 孪生」切换。管理端自己的侧栏保持 |
| 领域空状态 | 仍在图谱工作区中央，动作仍是回到健康领域 |

## 6. 状态、路由与偏好

### 6.1 分享 URL

- 工作区：继续用现有 `screen=explore` 与 `screen=twin`。不新增 `rail=` 参数。
- `screen=home` 或未写 screen：解析为图谱工作区（`explore`），保留 query 里仍然合法的 `theme`、`lens`、`layout`、`view`、`domain`。旧书签不 404。
- `pattern`、`compare`、`source` 仍写入 URL，但语义改为「当前工作区上的阅读层」，返回时去掉对应参数并留在 `explore`（或进入阅读层之前的工作区）。
- 复制链接仍复制工作区 + 图谱镜头，不复制左栏开合。

实现落点：`resolveScreen`、`serializeViewQuery` 与 `shareUrl.test.ts`。大厅专有的 `patterns` 高亮若左栏不再需要，序列化时停止写出；若「先看这些」仍要高亮某一张卡，用现有 theme / lens，不另造参数。

### 6.2 本地偏好

- `cleardiet.shellRail`：`expanded` | `collapsed`。仅桌面读取。手机忽略，每次进入默认全关。
- 不改 `themePreference`、`graphView`、饮食孪生 localStorage 的键。

### 6.3 断点切换

从桌面缩到手机：忽略占位栏，抽屉强制全关，避免半截栏卡在画布上。  
从手机放到桌面：按 `cleardiet.shellRail` 恢复；若用户没有存过，按宽度默认（≥1280 展开，否则图标栏）。

## 8. 分期

每一期一个 `cursor/*` 分支、一个指向 `main` 的 PR。合并顺序不可颠倒。

### PR-A 壳层骨架

- 桌面：大栏与图标栏占位切换，偏好写入本地。
- 手机：抽屉全开 / 全关，遮罩、Esc、打开后焦点。
- 工作区暂时只接图谱；顶栏主导航移除；品牌进左栏。
- 主题、筛选、搜索、领域从探索栏迁入大栏。大厅路由打开即图谱。
- 「先看这些」出现在大栏，点卡片行为与今天大厅进入主题 / 透镜一致。
- 孪生按钮先放在左栏，点击仍可暂时走现有整页 `DietTwin`（PR-B 再收成画布）。若希望 PR-A 不出现双轨体验，本项可只保留按钮并禁用，文案用「即将放进画布」——默认采用「PR-A 仍打开现有整页，PR-B 再换位」，避免中间版本丢功能。
- 测试：`shellRail` 纯函数；分享 URL 中 `home` → 图谱；现有 `palette.test.ts` 文案守卫。
- 浏览器：1440 与 390。桌面收起后画布变宽且节点仍可点选；手机打开抽屉后遮罩可关，选工作区后抽屉关闭。

### PR-B 孪生成为第二块画布

- `DietTwin` 拆成画布 + 左栏控件。
- 工作区切换不卸载本地记录；从指标回到图谱再返回，草稿还在。
- 图标栏下用「记录」按钮展开大栏。
- 浏览器：添加一条一句话记录，画布指标区仍可见教育标记；点指标进入图谱；再点「我的饮食」回到孪生。

### PR-C 阅读层与退场

- 来源页、饮食方式详情改为工作区覆盖层，返回留在图谱。
- 去掉已无引用的大厅整页样式与顶栏按钮。
- 核对免责声明在两种工作区、两种左栏、手机抽屉下都可见。
- 回归：`npm test`、`npm run validate:data`（本方案不改种子，验证作为壳层改动的保险）。

不做的事（三期都排除）：

- 不改节点坐标、`hierarchyBudget`、通路分带、搜索排序。
- 不改孪生问卷题目、映射和 localStorage 结构，除非拆组件时必须把 props 抬上去。
- 不把管理端嵌进用户左栏。
- 不加临床分数、饮食处方或「你的风险」文案。
- 不在手机上做常驻图标条。

## 9. 验收

1. 桌面 1440：左栏可在 280px 与 64px 间切换，切换后画布即时变宽或变窄，刷新后开合与上次一致。

6. 图谱内：搜索、主题、隐藏非匹配、节点详情、图例、复制链接与重构前一致。
7. 孪生内：教育标记始终可见；记录仍只在本地；从指标能回到对应图谱节点。
8. 免责声明未被左栏或抽屉挡住。
9. `npm test` 通过。

## 10. 风险

- **`App.tsx` 过重。** 壳层状态若继续堆在 App 里，PR-A 会和图谱焦点逻辑缠在一起。PR-A 先抽出 `Shell`，App 只保留数据与工作区选择。
- **大厅搜索与探索搜索重复。** 迁入左栏时只留一个 `SearchBar`，删除大厅里那份，避免两套空状态文案。
- **画布尺寸。** `GraphCanvas` 依赖容器尺寸。左栏展开/收起必须触发一次 resize（现有图组件若监听窗口，还要在栏宽过渡结束时派发或直接把容器 `ResizeObserver` 补上）。列入 PR-A 浏览器验收，不单靠截图。
- **焦点。** 手机抽屉打开时锁住背后画布的点击（遮罩 `pointer-events`），并避免屏幕阅读器同时读到画布与抽屉。抽屉使用 `aria-modal="true"`。
