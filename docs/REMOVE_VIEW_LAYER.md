# 取消全局模式切换，保留机制列

## 1. 目标

- 普通用户默认看到完整路径（含机制列）。
- 取消顶栏「普通 / 专家」全局切换。
- 技术细节放入抽屉底部「更多说明」折叠区，按需展开。

## 2. 图谱层次

四列始终显示：
- 膳食 / 食物
- 营养素 / 代谢物
- 机制
- 疾病 / 结局

不再因模式隐藏机制列。

## 3. 抽屉

点开边或节点后，默认显示：
1. 短引原文（excerpt）
2. 来源
3. 局限性
4. 方向与强度徽章

底部增加「更多说明」折叠区，展开后显示：
- 证据类型详细说明
- DOI / 文献链接（若有）
- audience / mechanism_depth（若有）

## 4. 界面

- 移除顶栏「普通 / 专家」切换按钮。
- 移除与 ViewLayer 相关的提示文案（如「已简化显示」「已展开全部证据」）。
- 抽屉「更多说明」默认折叠。

## 5. 数据

- 不改变 schema。audience 与 mechanism_depth 仍保留在数据中，仅不再用全局切换控制显示。
- 教育边界与免责声明不变。

## 6. 验收

- 四列始终可见，无需切换。
- 顶栏无「普通 / 专家」按钮。
- 点开边后，短引在上部，技术细节在折叠区。
- 免责声明始终可见。

以上供取消全局切换使用。
