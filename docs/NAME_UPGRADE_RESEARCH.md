# 项目名称升级研究（文化意境版）

> 最终采纳：中文主名 **明膳知源**（TASK-NS-021）；英文名 **ClearDiet**（TASK-NS-023）。TASK-NS-020「饮食球」方向作废。下文是选名研究记录，不是现行品牌。

## 定位回顾

面向普通大众的科普工具，唤醒对饮食重要性的重视，并让人知道怎么做。
名称不必强调与英文的直译对应，也不必强用「饮食」二字，可从中文语境与文化意象出发。

## 有意境的中文名称候选

| 名称 | 意象 | 优点 | 注意点 |
|------|------|------|--------|
| **食悟** | 从吃中悟到关系 | 自然、有启发感；呼应「看明白」 | 稍文艺 |
| **知味** | 知道食物的味道与影响 | 口语化、易记；有文化感 | 可能被理解为美食 |
| **膳思** | 思考膳食与健康 | 简洁、有思辨感 | 稍冷 |
| **食鉴** | 鉴别、查看饮食关系 | 工具感强；呼应可查询 | 稍专业 |
| **养源** | 养生之源在于食 | 文化感强；呼应重要性 | 需配合说明避免误解为补充剂 |
| **明膳** | 看明白膳食之道 | 直接、积极 | 稍宣传 |
| **食径** | 饮食的路径与方向 | 呼应探索与怎么做 | 较为直白 |
| **正味** | 正确的味道与选择 | 简洁、有判断感 | 可能偏主观 |
| **食观** | 观察与理解饮食 | 客观、研究向 | 稍冷 |
| **通膳** | 通晓膳食之道 | 口语化 | 稍广告 |

## 推荐优先顺序

1. **食悟**  
   有启发感，自然呼应「从吃中明白关系」，且不引发疗效联想。

2. **知味**  
   口语化、易传播，有文化温度；需在界面中明确区分于美食推荐。

3. **食径**  
   直接呼应路径与怎么做，与图谱 + 健康饮食方式板块一致。

4. **膳思**  
   简洁有思辨，适合教育定位。

## 选名原则（已应用）

- 不必与英文直译对应。
- 不必强用「饮食」二字。
- 有中文语境与文化意象。
- 避免疗效、诊疗、处方联想。
- 易记、口语化、不超过 3 字优先。

## 结论

当前更推荐 **食悟** 或 **知味** 作为中文主名。
若更想突出路径与怎么做，可选 **食径**。
