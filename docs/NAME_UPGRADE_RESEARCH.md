# 项目名称升级研究

## 背景

项目定位已明确：
- 面向普通大众的科普工具
- 唤醒大众对「饮食」重要性的重视
- 让大众知道「怎么做」
- 第一关键词是 **饮食**

现有名称 **NutriSphere** 对中文用户不够直接。
「饮食球」虽简洁，但「球」的意象对普通用户偏抽象，不够自然。

## 更好的中文名称候选

| 名称 | 英文副名建议 | 优点 | 缺点 | 推荐度 |
|------|----------------|------|------|--------|
| **饮食图** | DietMap | 直接、工具感强；呼应可查询、可探索 | 稍偏平面 | 高 |
| **饮食地图** | DietMap | 更具象，易理解为「可导航的饮食关系」 | 稍长 | 高 |
| **饮食关联** | DietLink | 强调关系与路径，与图谱定位一致 | 稍技术 | 中高 |
| **食养图** | FoodHealthMap | 呼应「吃什么」与健康；口语化 | 「食养」可能被理解为食疗 | 中 |
| **饮食明** | DietClear | 简洁，呼应「看明白」 | 偏宣传 | 中 |
| **饮食通** | DietPass | 通俗、易记 | 稍广告感 | 中 |

## 推荐优先顺序（替代「饮食球」）

1. **饮食图**（DietMap）  
   最平衡：直接、可记、工具感强，且不引发疗效联想。

2. **饮食地图**（DietMap）  
   更具象，适合强调「可导航」与「看清路径」。

3. **饮食关联**（DietLink）  
   若更想突出图谱与关系探索。

## 不建议的方向

- 过于抽象或难发音的词（如「球」「界」）。
- 容易产生疗效或诊疗联想的词（如「治」「修」「逆转」）。
- 过长的句子（如「饮食怎么做」）。

## 迁移建议

若确认新名称：
- 界面品牌、README、文档同步更新。
- 保留过渡说明「原 NutriSphere」。
- 免责声明与教育边界不变。
- 仓库名可保留或后续重命名。

## 结论

「饮食球」可用但不是最佳。
更推荐 **饮食图** 或 **饮食地图**，更自然、更贴近普通用户对「可查询的饮食关系工具」的理解。

请选择一个方向，或提供其他候选。
