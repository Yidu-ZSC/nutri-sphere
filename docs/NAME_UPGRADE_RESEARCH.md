# 项目名称升级研究

## 背景

项目定位已明确：
- 面向普通大众的科普工具
- 唤醒大众对「饮食」重要性的重视
- 让大众知道「怎么做」
- 第一关键词是 **饮食**（而不是更偏专业的“营养”或“机制”）

现有名称 **NutriSphere**：
- Nutri 来自 Nutrition，偏专业、英文为主
- Sphere 呼应三维/可探索空间
- 对中文用户而言，「饮食」这一核心词不直接
- 网上已存在其他 NutriSphere / NourishSphere 项目，区分度有限

## 是否应该升级？

**建议升级**。

理由：
1. 第一关键词已从「营养知识图谱」转向「饮食重要性 + 怎么做」。
2. 目标用户是普通大众，名称需更直接、更口语化。
3. 现有名称对中文用户的唤醒力偏弱。

## 方案比较

| 方案 | 优点 | 缺点 | 建议度 |
|------|------|------|--------|
| 保留 NutriSphere | 无迁移成本；已有仓库与历史 | 不体现「饮食」第一关键词；偏英文 | 低 |
| 中文主名 + 英文副名 | 直接呼应定位；便于传播 | 需同步更新仓库名、文档、品牌 | 高 |
| 完全英文新名 | 国际化友好 | 对中文用户唤醒力仍不够 | 中 |

## 推荐方向

**采用中文主名 + 英文副名**。

### 候选名称

1. **饮食球**（DietSphere / DietBall）  
   简洁、直接。「球」保留可探索空间的意象。

2. **饮食怎么做**（HowToEat / DietHow）  
   强调「怎么做」，与当前健康饮食方式板块强相关。稍长。

3. **饮食重要**（DietMatters）  
   直接呼应唤醒重视的目标。偏宣传感。

4. **饮食图**（DietMap / DietGraph）  
   强调图谱与关联。偏工具感。

### 推荐优先顺序
1. **饮食球**（DietSphere）—— 平衡直接性与可记忆性，且与原名有连续性。
2. **饮食图**（DietMap）—— 若更强调可查询、可探索的工具属性。

## 迁移建议

若决定升级：
- 仓库名可保留 `nutri-sphere` 或重命名（GitHub 支持重命名）。
- 文档、README、界面品牌同步更新为新名称。
- 保留一段过渡说明：「原 NutriSphere」。
- 免责声明与教育边界不变。

## 结论

结合当前定位（第一关键词是饮食，科普唤醒 + 知道怎么做），**建议升级名称**。
优先推荐「饮食球」作为中文主名，英文副名可使用 DietSphere。

请确认是否采用此方向，或提供其他候选名称。
