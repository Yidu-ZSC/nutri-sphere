# 抽屉内容优先级：普通用户看原文

## 1. 目标

普通用户点开节点或边后，先看到具体内容，而不是系统内部描述。

## 2. 节点说明

- 不使用「中间环节」「路径节点」等元语言。
- 使用资料里的具体描述，一两句即可。
- 示例：「持续存在的低度炎症状态，书摘里常把它和饮食选择、多种健康主题放在一起讨论。」

## 3. 边抽屉优先级（普通模式）

点开边后，抽屉按以下顺序展示：

1. **短引原文**（excerpt）— 最优先，用户最想看到的内容
2. **来源**（source_file 或文献标题）
3. **局限性**（limitations）
4. **方向与强度**（作为辅助徽章）
5. **证据类型**（徽章，不占主位置）

## 4. 专家模式

可额外展示：
- evidence_type 详细说明
- citation（DOI 链接）
- audience / mechanism_depth

但短引仍保持在最前。

## 5. 文案

- 短引保留原文语气，不改写成结论。
- 不添加「可以治疗」「建议你吃」等词。
- 局限性必须可见，不得因优先级调整而隐藏。

## 6. 验收

- 点开任意边，短引在抽屉上部可见。
- 节点说明不再出现「中间环节」等元语言。
- 普通模式下，用户无需滚动即可看到原文短引。
- 免责声明与教育边界不变。

以上供抽屉呈现优先级调整使用。
