## 3. 后台入口

- 路径：`/admin`（需登录或内部访问）
- 侧栏导航：图书管理、边管理、节点管理、数据校验、系统设置
- 当前优先实现「图书管理」

## 4. 图书管理页面

### 4.1 列表页
- 表格：书名、作者、出版年、相关度、已入库边数、状态、操作（NS-066 起不再展示笔记数）
- 筛选：主题、相关度、状态
- 操作：查看、编辑简介、查看关联边

### 4.2 详情页
- 基本信息：原名、作者、出版年、类型、简介、外部链接
- 本书被引用的边列表（可点击跳转图谱）
- 原始书摘文件链接（仓库 `data/kb/`）
- 操作：编辑简介、标记状态（已审核 / 待补充）

### 4.3 编辑
- 可编辑：简介、作者、出版年、外部链接、状态
- 不可编辑：书名、原始文件路径（由同步决定）

## 5. 后续可扩展

| 模块 | 说明 |
|------|------|
| 边管理 | 查看/扩充原文摘录、补充多来源 |
| 节点管理 | 机制与健康/疾病字典维护 |
| 数据校验 | CI 校验结果、缺失字段提示 |
| 来源同步 | 从知识库同步状态查看 |

## 6. 技术建议

- 初期：静态页面 + JSON 数据，与现有架构一致
- 后台与前台分离，不混入普通用户导航
- 教育边界不变，后台也不写疗效或建议
