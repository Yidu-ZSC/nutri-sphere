# 明膳知源全站专业 UI 重构方案

## 1. 定位与设计目标

面向普通用户的教育工具。目标：
- 清晰：一眼能看出保护/风险方向
- 亲切：减少技术感，增加引导
- 美观：现代、克制、有层次
- 统一：全站一套规范

不改变：教育边界、免责声明原文、数据字段。

## 2. 视觉规范（全站统一）

### 2.1 色彩
- 背景：`#0b0d12`（主）、`#16181d`（卡片）、`#1e2128`（悬停）
- 文字：`#f1f3f5`（主）、`#a1a8b3`（次）、`#6b7280`（弱）
- 方向：保护 `#34d399`、风险 `#f87171`、混合 `#fbbf24`、中性 `#94a3b8`
- 强调：品牌绿 `#10b981`（仅主按钮与重要标记）

### 2.2 空间与层次
- 间距：4 / 8 / 12 / 16 / 24 / 32 px
- 圆角：按钮 6px、卡片 10px、大面板 16px
- 阴影：轻量，仅卡片悬停时使用
- 边框：`1px solid rgba(255,255,255,0.08)`

### 2.3 字体
- 标题：16–20px 加粗
- 正文：14px
- 辅助：12px
- 系统字体栈，行高 1.5

### 2.4 组件
- 主按钮：实心绿，高度 36px
- 次按钮：描边或鬼影
- 徽章：小圆角，方向色左边条
- 输入框：深色背景 + 细边框，聚焦时绿色描边

## 3. 页面重构

### 3.1 大厅
- 顶部：品牌 + 一句话引导（「看清膳食与健康主题在公开资料里常被怎么一起讨论」）
- 主区：主题卡片网格（桌面 3 列，手机 1 列），卡片左上角方向色条
- 卡片内容：标题 + 一行说明 + 「查看关联」按钮
- 健康饮食方式：独立区块，三卡并排，带「查看详情」
- 底部：免责声明简版 + 「方法说明」链接

### 3.2 图谱探索页
- 左侧固定面板（桌面 280px）：主题列表 + 筛选，移动端收起
- 主图区：中间留白更充分，节点标签默认显示
- 右侧抽屉：点节点后从右滑出，宽度 360px，内容分层（标题、方向徽章、说明、来源、链回）
- 顶栏：搜索 + 普通/专家切换 + 返回大厅，紧凑一行
- 图例：左下角小卡片，不遮挡主图
- 空状态：居中提示 + 「选择主题」按钮

### 3.3 饮食孪生页
- 左：记录列表（可添加、删除）
- 右：当前状态卡片组（指标条 + 解读 + 链回）
- 顶部：永久「教育模拟，非诊断」标记
- 假设切换：顶部分段控制

### 3.4 健康饮食方式
- 卡片网格，每卡：一句说明 + 多吃/少吃要点 + 证据简述 + 局限性
- 点击进入详情或链回图谱

### 3.5 方法说明
- 对话框居中，最大宽度 560px
- 分区：你能得到什么 / 怎么用 / 如何解读 / 重要提醒
- 技术字段默认折叠

## 4. 交互细节

- 悬停：卡片轻微上浮 + 边框变亮
- 聚焦：可见聚焦环（绿色）
- 加载：骨架屏或轻量动画，不阻塞操作
- 空状态：带主操作按钮，文案≤ 20 字

## 5. 文案原则

- 单句≤ 20 字（免责声明长文例外）
- 用动词开头：选择主题、查看关联、添加记录
- 避免技术术语直接出现在主区域
- 不出现疗效、处方、诊断等词

## 6. 响应式

- 桌面：三栏（左面板 / 主图 / 右抽屉）
- 平板：两栏，抽屉覆盖
- 手机：单栏，抽屉为底部弹出，操作收入「更多」

## 7. 验收

- 桌面 1440 与手机 390 均能完成主流程
- 方向色在 3 秒内可识别
- 从大厅到图谱侧栏 ≤ 3 步
- 免责声明始终可见
- 无新增疗效或诊疗文案

## 8. 实现优先级

1. 建立全局样式变量（色彩、间距、字体）
2. 重构大厅与图谱页布局
3. 重构饮食孪生与健康饮食方式
4. 统一对话框与空状态
5. 移动端适配与文案守卫

以上供全站重构使用。
