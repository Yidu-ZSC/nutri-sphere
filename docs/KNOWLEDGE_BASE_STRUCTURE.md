# 知识库目录与规范

## 1. 目的

本知识库是 ClearDiet 的信息采集源。原始书摘只读保留，新采集按「待审 → 已入库」流转，与图谱 schema 对齐。

## 2. 目录结构

```
知识库/
├── 00-规范与索引/
│   ├── 采集规范.md
│   └── 索引.md
├── 01-待审/
│   ├── 书摘/
│   └── 文献/
├── 02-已入库/
│   ├── 机制/
│   ├── 结局/
│   └── 膳食与食物/
├── 03-原始书摘/
│   └── 00-索引.md
└── 04-参考/
    └── 公开数据源说明.md
```

## 3. 各目录说明

### 00-规范与索引
- 采集规则与总索引。
- 新增内容前先读规范。

### 01-待审
- 新提取的三元组或边，等待审核。
- 书摘来源放入 `书摘/`，文献来源放入 `文献/`。
- 文件命名：`待审_主题_日期.md` 或按边 id。
- 审核通过后移入 `02-已入库`，并同步到 GitHub 数据文件。

### 02-已入库
- 已合并进图谱的节点与边摘要。
- 按机制、结局、膳食与食物分类，方便回溯。
- 每条记录带 `node_id` 或 `link_id`，与主数据文件对应。

### 03-原始书摘
- 所有微信读书笔记扁平存放，不再分子目录。
- 只读，不修改原文。
- 文件名保留原有前缀，方便搜索。
- `00-索引.md` 列出全部书摘。

### 04-参考
- 公开数据源说明、外部引用备忘等。

## 4. 文件命名

- 原始书摘：保持现有名称（如 `肠道菌群_晓肚知肠.md`）。
- 待审：`待审_来源类型_主题_日期.md`。
- 已入库：`节点id.md` 或 `边id.md`，内容为摘要与来源引用。

## 5. 流转规则

1. 从 `03-原始书摘` 提取新边 → 写入 `01-待审`。
2. 人工审核：检查摘录准确性、局限性、是否越界。
3. 通过后移入 `02-已入库`，并更新 GitHub `data/` 主文件。
4. 拒绝的条目保留在待审并标注原因，或删除。

## 6. 与 ClearDiet 的对应

| 知识库目录 | ClearDiet 位置 |
|------------|----------------|
| 01-待审 | `data/pending/` |
| 02-已入库 | `data/seed_triples_*.json` |
| 03-原始书摘 | 研究助手查阅源 |
| 00-规范 | 采集规则 |

## 7. 边界

- 不修改原始书摘内容。
- 不在知识库中写剂量、疗效或个性化建议。
- 文献边必须带 DOI 或 PMID。
- 每条边保留局限性说明。

以上规范供后续采集与维护对齐使用。
