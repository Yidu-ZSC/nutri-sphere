# 「方法说明」面向用户的友好改写方案

## 定位

「方法说明」应是**面向普通用户的帮助入口**，而不是字段说明书。

用户打开后应能快速理解：
- 这里能得到什么
- 怎么用这个系统
- 如何解读图上的颜色、线条、文字
- 有什么限制

技术字段（type、group、schema_version 等）降级到可折叠的「给开发者看」区块，默认收起。

## 建议结构

### 1. 开头（一句话）
**明膳知源** 帮你看清膳食与健康主题在公开资料里常被怎么一起讨论。
供学习与核对来源，不是医疗建议。

### 2. 你能得到什么
- 从一个健康主题入手，看饮食与它常被怎么联系起来。
- 看到关联的方向（保护相关 / 风险相关）和证据强度。
- 查看每条说明的来源与局限性。
- 从「健康饮食方式」了解公开资料中常被描述的模式特征。

### 3. 怎么用
1. 在大厅选一个你想了解的主题。
2. 进入图后，点击线条或节点查看详细说明。
3. 用顶部切换「普通视图 / 专家视图」（普通视图更简洁）。
4. 想看「怎么做」，可进入「健康饮食方式」或从侧栏跳转。

### 4. 如何解读
- **颜色**：绿色表示资料里常被描述为保护相关；红色表示风险相关。颜色不是对你个人的判断。
- **线条粗细**：线越粗，表示资料中这条说明汇聚程度越高。
- **证据类型**：标明来源（书摘、观察研究等），不是临床等级。
- **局限性**：每条说明都会标明自己的限制，请一起看。

### 5. 收录范围（简化）
当前图中约有 {nodeCount} 个节点、{linkCount} 条关联。
材料主要来自公开书籍摘录，另有少量可核验的文献。
不覆盖全部研究，也不包含你的个人病历。

### 6. 重要提醒
这里展示的是公开资料中的关联说明，不是对你个人的建议或处方。
健康决策请咨询具备资质的专业人员。

### 7. 给开发者看（默认折叠）
- 字段对照表（type、group、direction、strength、evidence_type 等）
- 版本信息（schema_version、data_version、extraction_date）
- 证据类型列表与统计
- 维护说明

## 文案原则

- 用第二人称「你」，语气亲切。
- 单句不超过 25 字。
- 避免技术术语直接出现在主区域。
- 不承诺疗效，不给出个人处方。
- 免责声明长文仍可在底部或重要提醒区完整展示。

## 实现提示

- 主区域用新结构重写 `src/components/DisclaimerBar.tsx` 中的 about 对话框。
- 技术内容用 `<details>` 折叠。
- 动态数字（节点数、关联数）保留插值。
- 不改变免责声明原文。
- 新文案通过现有文案守卫。

## 验收

- 普通用户打开后能在 30 秒内理解「能得到什么」和「怎么用」。
- 技术字段默认不可见。
- 颜色、线条粗细的解读说明清晰。
- 无新增疗效或个人处方文案。

以上供开发对齐使用。
