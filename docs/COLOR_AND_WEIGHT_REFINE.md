# 绿色与字重全局优化

## 1. 绿色

### 现状
主按钮与强调绿使用 `#10b981`，在深色与清新主题下都偏重。

### 建议
- 主按钮填充：`#22c55e`（更亮）
- 悬停：`#16a34a`
- 按钮文字：白色，确保 4.5:1 对比
- 方向保护色（指标条等）：保持 `#34d399`，不与按钮混用
- 聚焦环：`#22c55e`，宽度 2px

### 原则
- 仅主操作按钮使用实心绿
- 次要按钮用描边或鬼影
- 不在卡片背景或大面积填充使用深绿

## 2. 字重

### 现状
标题、按钮、卡片标题、分段控制等多处加粗，层次不清。

### 建议规则
| 元素 | 字重 | 说明 |
|------|------|------|
| 页面标题 | 600 | 仅一级标题 |
| 卡片标题 | 500 | 正常，不加粗 |
| 按钮文字 | 500 | 正常 |
| 正文 | 400 | 默认 |
| 辅助说明 | 400 | 次要色 |
| 徽章 / 标签 | 500 | 可选 |

### 不加粗的地方
- 卡片内标题
- 按钮文字
- 分段控制文字
- 列表项主文字
- 指标名称

### 保持加粗的地方
- 页面一级标题
- 对话框标题
- 重要提醒短语（如「教育模拟，非诊断」）

## 3. 实现

- 更新全局 CSS 变量：`--accent`、`--accent-hover`
- 替换主按钮填充色
- 全局检查 `font-weight: 600/700`，按上表降级
- 更新 `docs/UI_PRO_REDESIGN.md` 中的色彩与字体规范

## 4. 验收

- 主按钮更亮，文字对比 ≥ 4.5:1
- 卡片标题与按钮不再全部加粗
- 层次更清晰，深色与清新主题均适用
- 方向色语义不变

以上供全局优化使用。
