# ClearDiet 多主题拓展方案

## 1. 目的

在「饮食与健康/疾病」基础上，拓展「饮食与环境」「饮食与文化」等主题，同时保持统一的知识图谱结构与教育边界。

## 2. 现有结构特征

当前是**具有结构性关系的知识图谱**：

- 节点类型：膳食模式 / 食物 / 营养 / 机制 / 健康或疾病
- 边：有方向、证据、来源、摘录
- 典型路径：饮食 → 机制 → 健康/疾病结果

这种结构适合「饮食如何影响某种结果」的叙事。

## 3. 新主题是否符合该特征

| 主题 | 典型路径 | 是否符合现有结构 | 说明 |
|------|----------|------------------|------|
| 饮食与环境 | 饮食选择 → 环境影响（碳排放、土地、水资源） | 部分符合 | 可抽象为「饮食 → 环境机制/过程 → 环境结果」，但机制与结果类型不同 |
| 饮食与文化 | 饮食实践 → 文化意义、传统、身份 | 较弱 | 更多是描述性关联，较少「机制链」，更接近主题网络 |

结论：
- **环境**可在现有结构上拓展，增加环境相关节点类型与边。
- **文化**更适合作为独立主题网络，节点与边语义不同，不强制套用「机制 → 结果」链。

## 4. 整体解决思路

### 4.1 多主题图谱
- 同一套节点/边 schema，增加 `domain` 字段：`health` / `environment` / `culture`。
- 界面按主题切换视图，默认仍是健康主题。
- 跨主题边（如「植物性饮食同时关联环境与健康」）允许存在，但需明确标注。

### 4.2 节点类型扩展
| domain | 新增节点类型示例 |
|--------|------------------|
| environment | 环境影响、碳排放、土地使用、水资源 |
| culture | 文化实践、传统节日、身份认同、地域饮食 |

### 4.3 边的复用
- 边结构不变：关系、方向、证据、来源、摘录。
- 环境与文化边同样需要来源与局限性，不写结论。

### 4.4 界面
- 顶栏或入口增加主题切换：健康 / 环境 / 文化。
- 切换后图谱只显示对应 domain 的节点与边。
- 来源简介页可显示该书在哪些主题下被引用。

## 5. 分阶段建议

**阶段 1（当前）**  
继续完善健康主题：摘录扩充、来源简介、后台图书管理。

**阶段 2**  
- schema 增加 `domain` 字段（默认 `health`）。
- 先做「饮食与环境」小范围试点（3–5 个节点、若干边），验证结构与界面。

**阶段 3**  
- 根据试点调整，再扩展环境主题或启动文化主题。
- 文化主题若路径差异大，可考虑独立子图，不强制统一机制链。

## 6. 边界

- 所有主题保持教育性质，不构成建议或结论。
- 来源可追溯，局限性可见。
- 不在未验证结构前大规模添加新主题数据。

## 7. 版本

- v0.1：多主题拓展整体思路，环境可扩展、文化宜独立评估。

以上供多主题拓展对齐使用。
