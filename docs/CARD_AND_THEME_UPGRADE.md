# 卡片灵动化与多主题方案

## 1. 卡片升级（灵动、清新）

### 1.1 视觉
- 背景：半透明或微渐变，避免纯平深色
- 左上角：方向色细条（2–3px），悬停时变亮
- 圆角：12px，轻量阴影
- 按钮：悬停时轻微上浮 + 亮度提升，不改变颜色语义

### 1.2 内容
- 标题：一行，加粗
- 说明：一行截断，次要色
- 按钮：全宽，高度 36px，圆角 8px
- 卡片间距：16px，网格对齐

### 1.3 交互
- 悬停：边框变亮 + 轻微上浮（2px）
- 点击：按钮有按下反馈
- 聚焦：可见聚焦环

## 2. 多主题

### 2.1 主题列表
| 主题 | 背景 | 卡片 | 文字主色 | 适用 |
|------|------|------|----------|------|
| 深色（默认） | `#0b0d12` | `#16181d` | `#f1f3f5` | 当前 |
| 清新 | `#f8fafc` | `#ffffff` | `#1e293b` | 白天使用 |
| 柔和 | `#f1f5f9` | `#ffffff` | `#334155` | 低对比 |
| 护眼 | `#1c1917` | `#292524` | `#fafaf9` | 暖色调 |

方向色（保护绿 / 风险红）在所有主题中保持一致。

### 2.2 实现
- 用 CSS 变量（`--bg`、`--card`、`--text` 等）。
- 主题切换存 localStorage（`cleardiet.theme`）。
- 顶栏右上角增加主题切换按钮（图标）。
- 默认深色，首次访问可选。

### 2.3 切换位置
- 大厅顶栏右侧
- 图谱页顶栏右侧
- 设置菜单（移动端）

## 3. 文案与边界

- 不改变教育边界与免责声明。
- 方向色语义不变。
- 主题切换不影响数据展示。

## 4. 验收

- 卡片悬停有反馈，视觉更轻。
- 可切换 4 套主题，刷新后保留。
- 方向色在所有主题中可识别。
- 移动端可切换主题。

## 5. 优先级

1. 卡片视觉与交互升级
2. 全局 CSS 变量与 4 套主题
3. 顶栏主题切换入口

以上供开发对齐使用。
