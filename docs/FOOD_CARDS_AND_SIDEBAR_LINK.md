# 食物/模式主卡片与图谱侧栏「查看相关饮食模式」建议方案

与现有定位与 `docs/ENTRY_COPY_AND_PATTERN_CARDS.md` 对齐。
健康饮食方式板块的三张并列卡片保持现状，暂不改为问题式。

## 1. 新增食物或饮食模式向的主卡片

### 目标
在主题大厅提供从「食物/模式」出发的入口，与现有疾病主题入口平行，但不增加过多决策负担。

### 建议方案
- 在主题大厅增加一个「从食物/模式看」区块（与疾病主题区块平行，位于其下或右侧）。
- 先放 3 张主卡片，保持与疾病卡片同等视觉重量，但数量更少。
- 卡片仍用问题式标题（与疾病入口一致），但过滤目标改为食物类别或膳食模式节点。

### 建议的 3 张主卡片

| id | 标题 | blurb | 过滤目标（示例） |
|----|------|-------|------------------|
| ultra-processed | 想看看超加工食品常被怎么描述 | 公开资料里常把它和某些健康主题放在一起说。 | 食物类别：超加工食品 |
| plant-based | 想知道植物性饮食与炎症常怎么一起出现 | 书摘与资料里常提到这条路径。 | 膳食模式：植物性为主 |
| dietary-fiber | 想了解膳食纤维常被怎么说 | 与菌群、炎症叙述常一起出现。 | 营养素/食物：膳食纤维 |

### 实现要点
- 新卡片放在 `src/lib/themes.ts` 的新常量中（例如 `HOME_FOOD_THEMES`），不与疾病主题混用。
- 点击后进入图谱，默认隐藏非匹配节点，普通层过滤仍生效。
- 若图谱中暂无对应节点，卡片可先显示但进入后提示「当前主题在普通层暂无匹配」（复用现有空状态）。
- 不改变现有疾病主题卡片的 id 与过滤。

### 为什么不一次性加太多
主入口卡片总数保持可扫描（疾病 9 + 食物/模式 3）。多了会回到「首屏决策负担大」的问题。

## 2. 图谱侧栏加「查看相关饮食模式」

### 目标
让用户从「为什么」图谱一键跳到「怎么做」模式卡片，完成互通。

### 建议方案
- 在图谱侧栏（点击节点或边后的抽屉）底部，当当前主题或选中节点存在相关模式时，显示一个文字链接或次要按钮：「查看相关饮食模式」。
- 点击后跳转到健康饮食方式板块，并高亮匹配的模式卡片（若多个则全部高亮）。
- 映射关系放在前端常量中（与现有模式卡片的 `related_themes` 对应）：
  - `cardiometabolic` → 地中海模式、DASH 模式
  - `chronic-inflammation` → 植物性为主模式
  - 其他主题暂不显示该链接
- 若当前无匹配模式，不显示该入口（避免空链接）。

### 文案
- 按钮文案：「查看相关饮食模式」
- 不使用「推荐你吃」「建议采用」等表述。

### 实现要点
- 侧栏组件中根据当前 `diseaseId` / `mechanismId` 查找映射。
- 跳转后保持用户可返回图谱（浏览器返回或明确的「返回图谱」按钮）。
- 移动端同样显示，不遮挡免责声明。

## 3. 优先级

1. 先做图谱侧栏「查看相关饮食模式」链接（低成本、完成互通）。
2. 再新增 3 张食物/模式主卡片（需确认图谱中已有对应节点或接受空状态）。

## 4. 约束

- 教育/研究工具边界不变。
- 新文案通过现有文案守卫。
- 不改免责声明原文。
- 健康饮食方式三张卡片保持现状，不改为问题式。

以上供开发对齐使用。
