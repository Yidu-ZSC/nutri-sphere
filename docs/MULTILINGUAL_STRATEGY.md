# 多语言策略

## 决定

完全采纳以下策略：
- 当前不立即做完整多语言。
- 中文为默认语言。
- 先做准备，有信号再启动英文版。

## 现阶段（立即执行）

1. 保持中文为默认语言，界面不改变。
2. 在页脚或关于页增加一句英文说明：
   > ClearDiet is currently available in Chinese. An English version is planned.
3. 确保品牌名「明膳知源 / ClearDiet」与域名 cleardiet.org 在英文环境下可识别。

## 下一步（有信号后）

- 先做 **中英双语**，而不是一次上多种语言。
- 优先翻译：大厅引导、主题标题、健康饮食方式卡片、「方法说明」、免责声明。
- 图中的证据摘录可保留原文，并标注「原文为中文」。

## 触发条件（满足任一即可启动英文版）

- Cloudflare / 分析显示持续有非中文地区访问。
- 收到明确的英文用户反馈。
- 计划主动面向海外华人以外的英文用户。

## 不急于做完整多语言的原因

- 完整多语言需要持续维护文案、证据说明和局限性，成本不低。
- 当前核心价值在于中文用户能看懂「为什么」和「怎么做」。
- 先把中文体验打磨好，再扩展语言更稳妥。

## 实现提示

- 现阶段只需增加一句英文说明，不改变现有中文界面。
- 后续若启动英文版，可用前端 i18n（如 react-i18next），文案与图数据分离。
- 免责声明需提供对应语言版本，教育边界不变。

以上供开发对齐使用。
