# ClearDiet 来源简介页专业性提升

## 1. 目的

来源简介页是用户从边延伸阅读的入口。当前信息过简、视觉偏平，需提升信息密度与专业感，同时保持教育边界。

## 2. 信息补充

来源简介区建议增加：

| 字段 | 说明 | 示例 |
|------|------|------|
| 原名 | 图书或文献全称 | 晓肚知肠 |
| 作者 | 完整作者名 | 段云峰 |
| 出版年 | 出版或发表年份 | 2018 |
| 类型 | 图书 / 综述 / 论文 | 图书 |
| 简介 | 2–4 句，说明本书关注什么、与饮食健康的关联 | 介绍肠道微生物与日常健康问题的科普读物。书中讨论了菌群多样性、发酵食物、膳食纤维等与肠道及整体健康的关系。 |
| 被引用边数 | 本系统中引用该书的边数量 | 7 条 |
| 外部链接 | 如有出版社或公开资料链接 | 可选 |

数据上在 `sources` 表补充 `type`、`summary`（更长简介）、`edge_count`。

## 3. 布局建议

页面结构（自上而下）：

1. **顶栏**：返回 + 面包屑「图谱 / 来源 / 晓肚知肠」
2. **来源卡片**（主视觉）
   - 左侧：书名（大字）、作者 · 年份、类型徽章
   - 右侧或下方：2–4 句简介
   - 底部小字：本系统引用了 N 条相关描述
3. **本书被引用的边**
   - 每条边卡片：起点 → 终点（主标题）、关系描述（副标题）、方向徽章
   - 点击跳回图谱并高亮该边
   - 支持按方向筛选（保护 / 风险 / 全部）
4. **底部**：免责声明

## 4. 视觉与易用性

- 来源卡片与边列表之间留足间距，避免拥挤。
- 边卡片 hover 时轻微提亮，明确可点击。
- 书名与作者层级清晰：书名 font-weight 600，作者与简介 font-weight 400。
- 颜色沿用项目主题，不新增深绿色。
- 移动端：来源卡片与边列表垂直堆叠，边卡片全宽。

## 5. 边界

- 简介只说明公开资料中的内容范围，不写疗效或建议。
- 不展示文件名。
- 免责声明始终可见。
