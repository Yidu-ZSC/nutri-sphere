# 抽屉布局优化：节点与边

## 1. 当前内容

### 1.1 点击节点
右侧抽屉显示：
- 标题（节点名称）
- 类型（机制 / 疾病风险 等）
- 分组（保护相关 / 风险相关）
- 说明（一两句具体描述）
- 别名
- 更多说明（折叠）
- 相关关联列表（点击可跳转到对应边）

### 1.2 点击边
右侧抽屉显示：
- 标题（关系描述）
- 起止节点（A → B）
- 摘录（excerpt）
- 来源文件
- 局限性
- 方向 / 证据类型 / 强度徽章
- 更多说明（折叠）

## 2. 优化目标

- 节点与边的抽屉结构对齐，减少跳跃感。
- 普通用户优先看到具体内容，技术字段折叠。
- 相关关联列表更易扫描。

## 3. 建议布局

### 3.1 节点抽屉
1. **标题**：节点名称（大号）
2. **方向徽章**：保护 / 风险（左侧色条）
3. **说明**：1–2 句具体描述
4. **相关关联**：卡片列表，每卡一行关系 + 方向色点，点击跳转
5. **更多说明**（折叠）：类型、别名、mechanism_depth 等

### 3.2 边抽屉
1. **标题**：关系描述（大号）
2. **起止**：A → B（可点击跳转节点）
3. **短引原文**：excerpt，最优先
4. **来源**：书名或文献标题
5. **局限性**：短句
6. **方向 / 强度徽章**：辅助
7. **更多说明**（折叠）：证据类型详细、DOI 等

## 4. 视觉

- 标题 16–18px，正文 14px，辅助 12px。
- 分区间距 16px，卡片内边距 12px。
- 相关关联卡片：左侧方向色条，悬停边框变亮。
- 折叠区默认收起，标题用次要色。

## 5. 文案

- 不使用「中间环节」「路径节点」等元语言。
- 短引保留原文语气。
- 不添加疗效或个性化建议。

## 6. 验收

- 点击节点：说明与相关关联在上部，技术字段在折叠区。
- 点击边：短引在上部，来源与局限性可见。
- 两种抽屉结构对齐，无需全局切换。
- 免责声明始终可见。

以上供抽屉布局优化使用。
