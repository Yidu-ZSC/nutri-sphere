# ClearDiet 原文摘录扩充规范

## 1. 问题

当前多数边的 excerpt 是系统生成的概括句（如「胰岛素抵抗在书摘中位于心血管与代谢风险的机制链上」），不是书摘原文。用户无法从中理解作者在表达什么。

## 2. 要求

- 摘录必须来自知识库对应笔记的原文，保留原语气。
- 长度以能让用户理解这条边在讲什么为准，目标 400–800 字（或原笔记完整相关段落）。
- 不改写成结论，不添加疗效或建议。
- 局限性仍单独保留在 limitations 字段。

## 3. 扩充流程

1. 从边的 source_file 与 note_id 定位知识库原文。
2. 截取能支撑 source → target 关系的连续段落。
3. 替换现有 excerpt。
4. 若同一书有多处相关内容，放入 evidences 数组的后续条目。

## 4. 优先级

先扩充以下主题相关边：
- 心血管 / 代谢
- 慢性炎症
- 肠道菌群与屏障
- 脂肪肝
- 炎症性肠病

其余边后续逐步扩充。

## 5. 验收

- 点开边后，原文摘录能让普通用户理解作者在讲什么。
- 摘录来自知识库原文，不是系统概括。
- 局限性仍可见。
- 教育边界不变。

以上供摘录扩充对齐使用。
