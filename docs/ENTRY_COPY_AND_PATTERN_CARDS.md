与 `docs/ENTRY_AND_HOW_TO_RESEARCH.md` 结论对齐。所有文案保持教育语气，不承诺疗效、不给出个人处方。

- 「想了解慢性炎症与饮食的讨论」

### 页头引导语（可替换现有）
> 先选一个你想了解的问题，再看公开资料里饮食与它常被怎么一起讨论。供学习与核对来源，不是医疗建议。

## 2. 「健康饮食方式」板块卡片结构草案

与现有图谱平行的「怎么做」入口。可用顶部切换（「看关联」| 「看模式」）或独立卡片区。

### 卡片字段

| 字段 | 说明 |
|------|------|
| id | 唯一标识 |
| title | 模式名称（如「地中海模式」） |
| summary | 一句话说明（≤40 字） |
| emphasize | 公开资料中常提到的「多吃」要点 |
| limit | 公开资料中常提到的「少吃」要点 |
| evidence_note | 证据类型与来源简述 |
| limitations | 必填：个体差异、非个人处方、非原创研究 |
| related_themes | 可跳转到的图谱主题 id |

### 示例卡片（草案）

#### 地中海模式
- **summary**：公开资料中常被描述为以蔬菜、水果、豆类、全谷物、橄榄油为主的模式。
- **emphasize**：蔬菜、水果、豆类、坚果、全谷物、橄榄油、鱼类
- **limit**：红肉、加工肉类、添加糖饮品、超加工食品
- **evidence_note**：多个心血管预防指南与综述将其与心血代谢结局联系起来（观察与部分干预证据）。
- **limitations**：个体差异大；不是个人处方；本项目不做原创研究。
- **related_themes**：`cardiometabolic`

#### DASH 模式
- **summary**：公开资料中常被描述为强调蔬菜、水果、低脂乳制品与全谷物，并限制钠与饱和脂肪的模式。
- **emphasize**：蔬菜、水果、低脂乳制品、全谷物、豆类、坚果
- **limit**：高钠食物、红肉、添加糖、饱和脂肪较高的食物
- **evidence_note**：多个指南将其与血压与心血管结局联系起来。
- **limitations**：同上。
- **related_themes**：`cardiometabolic`

#### 植物性为主模式
- **summary**：公开资料与书摘中常描述为以全食物植物为主、限制动物性食物与超加工的方式。
- **emphasize**：蔬菜、豆类、全谷物、水果、坚果种子
- **limit**：动物性食物、超加工食品
- **evidence_note**：书摘机制描述为主，辅以部分观察与综述。
- **limitations**：同上；个体营养需求差异大。
- **related_themes**：`chronic-inflammation`、`cardiometabolic`

### 互通关系
- 从模式卡片可跳转到相关图谱主题（带过滤）。
- 从图谱侧栏可提示「查看相关饮食模式」（若存在）。
- 两边共用同一套证据与局限性规则。

## 3. 实现提示

- 主入口文案改写可先改 `src/lib/themes.ts` 中的 `title` 与 `blurb`，不改 id 与过滤逻辑。
- 健康饮食方式板块可先做静态卡片（前端常量），后续再接图谱跳转。
- 所有新文案需通过现有文案守卫（无疗效、处方、诊断等词）。

以上供产品与工程对齐使用。
