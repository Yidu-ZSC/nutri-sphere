# NutriSphere UI 专业性提升规格

目标：在不改变教育/研究定位、免责声明原文、数据字段的前提下，提升功能布局、美观度、易用性与提示语简洁度，形成统一的产品级视觉规范。

## 1. 统一视觉规范

- **色彩**：保护绿 `#4ade80`、风险红 `#f87171`、混合黄 `#fbbf24`、中性灰 `#94a3b8`不变。背景用深色低对比（`#0f1115` / `#1a1d24`），文字主色 `#e8eaed`，次要文字 `#9aa0a6`。
- **间距**：卡片内边距 16–20px，组间 12–16px，顶栏高度统一。
- **圆角**：卡片 / 按钮 8px，大面板 12px。
- **字体**：系统字体，标题 16–18px加粗，正文 14px，辅助 12px。
- **按钮**：主按钮实心，次要按钮描边或鬼影；悬停/聚焦状态明确。
- **对比度**：文字与背景比 ≥ 4.5:1（普通文字）。

## 2. 主题大厅

- 卡片网格：桌面 3 列，平板 2 列，手机 1 列；卡片等高、左对齐。
- 卡片内容精简：标题加粗，blurb 一行截断，去掉重复的「教育向整理」前缀（已在页头说明）。
- 悬停：轻微上浮 + 边框高亮；聚焦环可见。
- 机制折叠区保持默认收起，标题改为「进阶机制主题（可选）」。

## 3. 探索页（图区）

- 顶栏：品牌左、主要操作右；搜索与筛选在桌面端保持可见，移动端收入图标按钮。
- 图例与统计：左下角紧凑，不遮挡主图；统计改为「当前可见 N 节点 · M 关联」。
- 层级提示：缩短为一行，放在顶栏下方细条，不占用大面积。
  - 普通：「已简化显示」
  - 专家：「已展开全部证据」
- 空状态：居中、带一个主按钮，文案不超过 20 字。

## 4. 侧栏 / 抽屉

- 宽度桌面 360px，移动端底部抽屉（不遮挡免责声明）。
- 标题加粗，证据徽章一行展示（方向色块 + 强度 + 证据类型）。
- 摘录与局限性分开，局限性用次要色。
- 关闭按钮固定右上，易点。

## 5. 提示语原则

- 单句不超过 20 字（免责声明长文例外）。
- 用动词开头：「选择主题」「查看关联」「已简化」。
- 避免重复说明；免责声明仅底栏完整展示，其他地方用短版。
- 不出现疗效、处方、诊断等词。

## 6. 移动端

- 顶栏操作收入「更多」菜单，避免挤在一行。
- 卡片与按钮点击区域 ≥ 44px。
- 抽屉支持下拉关闭。

## 7. 验收

- 桌面 1440 与手机 390 均能读到主标题与方向色。
- 从大厅进入主题到点开侧栏，步骤 ≤ 3 步。
- 提示语无冗余，免责声明始终可见。
- 无新增疗效或诊疗文案。

实现时保持现有功能不回退，仅做视觉与信息层次优化。
