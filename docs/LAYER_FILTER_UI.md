# 普通层过滤 UI 行为规格

目标：普通用户默认看到更干净、更易读的图；专家层可展开全部。

## 规则

### 普通层（layperson，默认）
- 边：仅显示 `audience` 为 `general` 或缺省的边（缺省视为 general）。
- 节点：
  - 机制节点：仅显示 `mechanism_depth` 为 `summary` 或缺省的。
  - 非机制节点：全部显示（不受 mechanism_depth 限制）。
- 主题过滤仍生效：先按主题取邻域，再应用上述层级过滤。
- 「隐藏非匹配」仍可用，且主题进入时默认开启。

### 专家层（expert）
- 显示全部节点与边（包含 `deep_reader` 与 `technical`）。
- 侧栏展开更多字段（原始 enum、note_id、citation 等）。

## UI 表现

- 切换层级时，图立即重新渲染（不重载整页）。
- 顶栏或图例附近显示当前层级提示：
  - 普通：「已简化显示」
  - 专家：「已展开全部证据」
- 若普通层过滤后当前主题无可见内容，显示「暂无匹配，可切专家层」，并提供主按钮「切换专家层」（只切换层级，不改主题锚点）。
- 切换不改变已选主题与分享 URL 中的 disease/mechanism/theme。

## 实现提示

- 过滤逻辑放在 `src/lib/` 或视图层，单测覆盖：
  - 普通层隐藏 deep_reader 边
  - 普通层隐藏 technical 机制节点
  - 专家层全部可见
- 不改变种子数据原文，不新增疗效文案。

见 `docs/NEXT_STEPS_DENSITY_DATA_UX.md` 第 1 节。
