# 健康饮食方式板块完整应用与呈现方案

定位：与现有图谱「为什么」对等的「怎么做」板块。
目标：让普通用户能清晰看到公开资料中常被描述的健康饮食模式是什么、核心要点是什么、如何与现有图谱关联起来。
约束：教育/研究工具；不给出个人处方或剂量；不承诺疗效；每条内容带来源与局限性；数据来自公开书籍与有公信力来源。

## 1. 信息架构

从浅到深三层：

1. **大厅卡片**（已有）：一句话 + 多吃/少吃要点 + 证据简述 + 局限性 + 查看相关主题。
2. **模式详情页**（新增）：点卡片进入，展开完整说明。
3. **与图谱互通**（已有部分）：从详情页或侧栏跳回图谱相关主题。

## 2. 模式详情页结构

每个模式一个详情页，分区呈现：

### 2.1 头部
- 模式名称
- 一句话总结
- 证据徽章（观察 / 综述 / 书摘机制等）

### 2.2 核心特征
- **多吃**：卡片列表（蔬菜、豆类、全谷物…）
- **少吃**：卡片列表（超加工、加工肉类…）
- 每项可展开短说明（公开资料中常提到的理由，带来源）

### 2.3 典型一天示例（非处方）
- 三餐示例（早、午、晚），用「公开资料中常见的组合方式」描述。
- 明确标注：「仅为说明模式特征，非个人食谱」。

### 2.4 与图谱的关联
- 「在图谱里看相关讨论」按钮，跳转到已映射的主题（带过滤）。
- 列出 1–2 条典型路径文字（如「植物性为主 → 慢性炎症 → 心血代谢主题」），点击可进入图谱。

### 2.5 证据与局限性
- 证据类型与主要来源（书摘 / 指南综述 / 观察研究）。
- 局限性固定文案：个体差异大；非个人处方；本项目不做原创研究；健康决策请咨询专业人员。

### 2.6 对比入口
- 页面底部「与其他模式对比」链接，进入简单对比表（见第 3 节）。

一个独立页面或大厅内嵌入的对比表：

## 4. 大厅呈现优化

- 三张卡片保持并列。
- 每张卡片增加「查看详情」按钮（进入详情页）。
- 大厅底部增加「对比三种模式」入口。
- 页头简短说明：「公开资料中常被描述的健康饮食方式。供学习参考，不是个人处方。」

## 5. 互通关系

- 大厅卡片 → 详情页
- 详情页 → 图谱相关主题
- 图谱侧栏「查看相关饮食模式」→ 大厅并高亮对应卡片（已有方向）
- 详情页也可返回大厅

## 6. 数据与实现

- 先用前端常量存储模式详情内容（扩展现有卡片字段）。
- 后续可迁移到 `data/` 下的结构化 JSON，便于验证与扩展。
- 路由：`/patterns`（大厅）、`/patterns/:id`（详情）、`/patterns/compare`（对比）。
- 分享 URL 支持直接打开某个模式详情。

## 7. 文案规则

- 用「公开资料中常被描述为…」「多个指南与综述将其与…联系起来」。
- 避免：建议你吃、治疗、预防、逆转、剂量、个人食谱。
- 典型一天示例必须带「非个人处方」标注。

## 8. 验收标准

- 普通用户从大厅卡片能进入详情页，看清核心要点与局限性。
- 能从详情页跳到相关图谱主题。
- 对比表可读，不引导排名感。
- 无新增疗效或个人处方文案。
- 移动端可读。

## 9. 优先级

1. 先做三个模式的详情页（基于现有卡片内容扩展）。
2. 再做简单对比表。
3. 最后完善与图谱的双向跳转与分享 URL。

以上方案保持教育边界，同时让「怎么做」板块具备完整可用的应用与呈现能力。
