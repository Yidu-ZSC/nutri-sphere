# ClearDiet 个人饮食个性化数字孪生策划方案

## 1. 全球相关项目概览

当前全球「饮食数字孪生」主要分为三类：

| 类型 | 代表 | 特点 | 与 ClearDiet 的差异 |
|------|------|------|-------------------|
| 临床/精准营养 | Twin Health、NOURISH、DDtwin | 传感器 + AI 预测血糖/代谢，面向糖尿病等疾病管理 | 临床定位，需医疗数据，不是教育工具 |
| 科研原型 | iDT-diet（Yeshiva）、菌群代谢模型（ISB）、肝脏孪生（HEPATWIN） | 机制模型 + 长期预测 + 3D 可视化，多为研究阶段 | 精度高但复杂，不面向普通用户即时使用 |
| 教育模拟 | Healthy Choice（Lehigh）、部分代谢模拟器 | 情景模拟、决策训练，强调素养素养 | 偏专业培训，缺少「记录-查看」闭环 |

**结论**：目前没有一个面向普通大众、明确标注「教育模拟、非诊断」、与公开资料图谱紧密结合的轻量个性饮食孪生。ClearDiet 可以做这个空白。

## 2. ClearDiet 的定位

**教育性个人饮食孪生**，不是医疗数字孪生。

- 用户输入饮食日志或简单问卷。
- 系统生成简易可视化（炎症热点、菌群多样性条等）。
- 用户假设改变饮食，看到可视化动态更新。
- 每个变化都链回现有图谱中的公开资料说明。
- 明确标注：**「模拟，非诊断」**。

目标：让用户学完「为什么」和「怎么做」后，能有一个轻量闭环去实践并看到反馈。

## 3. 核心原则

1. **教育边界**：不输出个人风险分数、诊断、处方或剂量。
2. **可追溯**：每个可视变化对应图谱中的节点/边与来源。
3. **简单输入**：问卷或简单日志，不要求传感器或检验数据。
4. **模拟标注**：界面持久显示「教育模拟，非诊断」。
5. **与现有板块互通**：从孪生可跳回图谱相关主题，也可跳到健康饮食方式。

## 4. 用户流程

1. **入口**：大厅或侧栏「我的饮食孪生」。
2. **输入**：
   - 简单问卷：近期植物性食物比例、超加工频率、纤维感受等（不采集疾病诊断）。
   - 或粘贴简单饮食日志（早、午、晚各一句话）。
3. **生成孪生**：简易 3D 人体轮廓 + 关键指标条。
4. **假设改变**：用户选「多吃蔬菜」「减少超加工」等，看到指标条与热点动态变化。
5. **链回来源**：点击变化点，跳到图谱中对应主题或边。
6. **记录**（可选）：本地保存假设历史，不上传服务器。

## 5. 可视化设计

### 5.1 主视图
- 简易 3D 人体轮廓（非写实）。
- 炎症相关热点：颜色深浅表示「公开资料中常被描述的炎症关联强度」（非个人检测）。
- 菌群多样性条：水平条，按植物性比例映射。

### 5.2 指标条（示例）
| 指标 | 映射逻辑（教育向） | 链回图谱 |
|------|----------------------|----------|
| 植物性比例 | 问卷/日志推断 | 植物性膳食模式节点 |
| 超加工频率 | 问卷/日志推断 | 超加工食品节点 |
| 纤维感受 | 问卷 | 膳食纤维节点 |
| 炎症关联 | 上述组合的教育权重 | 慢性炎症节点 |

权重与映射公式放在前端常量中，明确标注「基于公开资料的教育模拟，非个人生理测量」。

### 5.3 动态更新
用户调整假设（滑块或按钮）后，指标条与热点平滑过渡，不给出数字分数。

## 6. 技术实现建议

- 前端：Three.js 或现有 force-graph 技术栈扩展，简易人体模型 + 指标条。
- 数据：不需要后台数据库；问卷答案与假设历史存本地 localStorage。
- 映射：前端常量表（与图谱节点 id 对应）。
- 分享：可生成当前假设的分享链接（带模拟标注）。

## 7. 文案规则

- 用「公开资料中常被描述为…」。
- 持久显示：「这是教育模拟，不是你个人的健康检测或诊断」。
- 避免：你的风险是…、建议你吃…、治疗、预防、逆转。

## 8. 验收标准

- 普通用户能在 2 分钟内完成问卷并看到孪生。
- 调整假设后可视化有反馈。
- 点击变化点能跳到图谱。
- 持久可见「模拟，非诊断」标注。
- 无个人健康数据上传服务器。

## 9. 优先级

1. 先做问卷 + 静态指标条（无 3D），验证映射与链回。
2. 再加简易 3D 人体轮廓与热点。
3. 最后加本地历史记录与分享。

以上方案保持教育边界，同时为用户提供「记录改变—查看结果」的轻量闭环。
