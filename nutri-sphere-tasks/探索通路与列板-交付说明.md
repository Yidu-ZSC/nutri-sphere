## 行为

- **通路（默认）**：`view=flow` 或无有效 `view` 时打开 SVG 通路。列顺序与 `layout.ts` 一致。HUD 为「通路上 N 条…」；图例说明带子宽度。
- **通路交互**：拖动平移、滚轮以指针为中心缩放、双击空白重新取景。拖动超过阈值不会误点节点或带子。
- **层次**：原四列 2D 弦图（`view=2d`），统计仍为「当前可见 … 概念 · … 关联」。
- **列板**：原「3D 探索」改为 **列板**（`view=3d`）。四块竖直板对应四列，沿用 `selectFlowBands` 与 `layoutFlow` 的节点顺序；带子为 3D 带状网格。拖动仅小幅绕 Y 转动（`SLAB_YAW`），滚轮缩放，双击空白回到正面。侧栏「旋转开/关」仍控制列板缓慢自转。
- **主题 / URL**：进入主题、打开节点或书摘关联时仍优先切到通路；列板与通路共用同一套 `flowGraphStats` 文案（列板视图下 HUD 与通路一致）。

## 复现

```bash
npm ci
npm test
npm run validate:data
npm run build
npm run dev
```

1. 打开 `?screen=explore&theme=fatty_liver&view=flow&hide=1`。应见四列通路，统计含「通路上 … 条」。滚轮放大、拖动平移、双击空白回正。
2. 点节点与带子，侧栏与 URL `node=` / `link=` 与原先一致。
3. 切「列板」。四列立起，带子可见；小幅拖动转动；点带子打开关联抽屉。
4. 切「层次」确认 2D 仍可用。

## 约束核对

- 同列边、超预算跨列边仍在数据与搜索中，只是不画成带子。
- 自由力导向 3D 粒子云已不作为默认升级路径；列板为 2.5D 列语义 + 有限深度。
- 本环境 `npm test`、`npm run validate:data` 在合并后于 `main` 通过。
